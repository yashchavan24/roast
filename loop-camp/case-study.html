Project 2 · Brief-to-Output Case Study

Bright brand, real constraints: a kids coding camp that parents trust and kids pick..

"We run a summer coding camp for kids aged 8–14. Our buyer is the parent, but our user is the kid. Fill 20 seats per batch for June. Make it feel fun without feeling childish." Fictional client brief · Loop Camp · deliverables: identity + social + display

The tension I designed for

Kids' education ads usually fail on one side or the other: rainbow-and-comic-sans work on kids and lose parents' trust, or corporate-clean convinces parents and bores the kids who'll actually ask to go. The winning platform: "learning to code feels like a game" — borrow the visual language of pixel games and sticker sheets (kid energy) but execute it with a strict grid, real type system and restrained copy (parent trust).

The direction I killed

Direction A · Rejected

"Robo Buddies" — mascot-first

A wide-eyed robot mascot waving across every layout, comic bursts, rainbow gradients everywhere.

Why it diedIt talks down to 12-year-olds — the hardest audience to impress. It also ages the brand instantly and buries the actual product: they build a real game. Mascots are a crutch when the idea is weak.
Direction B · Rejected

"Future Engineer" — corporate-clean

Stock photos of kids at laptops, navy + grey, circuit-board dividers, "STEM-certified curriculum" badges.

Why it diedConvinces the parent, never reaches the kid — and the kid is the one who has to want it. Every competitor in the category looks like this, so it blends into the feed instead of stopping the scroll.

The winning direction: "Loop Camp — Summer of Code"

Pixel-game energy, designer's discipline.

Warm paper background instead of stark white; one electric grape for every call-to-action; lime, mint and sunshine as fixed roles (highlight, secondary, sticker) — never random. The pixel-cluster mark scales from favicon to skyscraper. Copy is short, verb-first, one joke per layout: "Screen time you'll actually brag about" targets the parent's guilt; "They build the game" targets the kid's status.

Space Grotesk — blocky, friendly, never childish.

Inter for body and UI copy. Monospace reserved for code moments — it appears exactly where code appears, nowhere else.

Final outputs — identity, social, display

Same system across every touchpoint: the mark, the grape CTA, the pixel deco, the voice. Format changes the layout, never the brand.

Full identity system (logo construction, palette, type, voice) → identity.html

What I'd carry into the next brief

  • Two audiences, one layout. The story speaks to the parent in the headline and the kid in the code window — dual-audience briefs need both voices in one composition, not two campaigns.
  • Constraints are the brand. Lime only ever highlights, grape only ever acts, sunshine only ever stickers. Fixed color roles are what keep playful from becoming chaotic.
  • Range is deliberate. This project pairs with my dark, premium coffee campaign (Roast Theory) to show the same process producing opposite registers — system-first thinking, not a personal aesthetic.
