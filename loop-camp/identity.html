Loop Camp.

A summer coding camp for kids aged 8–14. Identity built on one idea: learning to code feels like a game — so the brand borrows the visual language of pixel games, sticker sheets, and notebook doodles.

The mark is a 2×2 pixel cluster — one square per discipline: purple = code, lime = games, sunshine = builds, mint = teamwork. It scales from favicon to banner without redrawing. Inverse lockup (right) for purple surfaces.
